# Оцінка камер Caddx

Окремий статичний односторінковий сайт українською мовою. HTML і CSS, без JavaScript, залежностей, зовнішніх шрифтів або обов’язкової збірки.

## Локальний запуск

У цій директорії виконайте:

```sh
python3 -m http.server 3001 --bind 127.0.0.1
```

Обидва посилання Telegram працюють без JavaScript. Адреса задана у двох елементах `a` в `index.html`.

## Netlify

Завантажте цю директорію через Netlify Drop або підключіть її як окремий репозиторій. Команда збірки не потрібна, каталог публікації — `.`. Секрети та змінні середовища не потрібні.

Шрифти та їхні ліцензії розташовані в `assets/`.
