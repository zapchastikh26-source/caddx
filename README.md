# Оцінка камер Caddx

Окремий статичний односторінковий сайт українською мовою. HTML і CSS, без залежностей, зовнішніх шрифтів або обов’язкової збірки. JavaScript використовується для аналітики TikTok.

## Локальний запуск

У цій директорії виконайте:

```sh
python3 -m http.server 3001 --bind 127.0.0.1
```

Обидва посилання Telegram працюють без JavaScript. Адреса задана у двох елементах `a` в `index.html`.

## TikTok Pixel

Піксель `DBD02BJC77UASCMGFR6G` надсилає перегляд сторінки. Відстеження натискань Telegram налаштоване користувачем через конструктор подій TikTok як «Початок оформлення замовлення» (`InitiateCheckout`). Власних викликів `Contact` і серверної відправки Events API у сайті немає. Правила конструктора зберігаються в TikTok, а не в репозиторії; перевіряйте їх у Test Events. Натискання кнопки не підтверджує відправлення повідомлення в Telegram.

## Netlify

Підключіть репозиторій у Netlify. Команда збірки не потрібна, каталог публікації — `.`. Серверні функції та токени Events API для цього сценарію не потрібні.

Шрифти та їхні ліцензії розташовані в `assets/`.
