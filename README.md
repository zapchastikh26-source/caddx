# Оцінка камер Caddx

Окремий статичний односторінковий сайт українською мовою. HTML і CSS, без залежностей, зовнішніх шрифтів або обов’язкової збірки. JavaScript використовується для аналітики TikTok.

## Локальний запуск

У цій директорії виконайте:

```sh
python3 -m http.server 3001 --bind 127.0.0.1
```

Обидва посилання Telegram працюють без JavaScript. Адреса задана у двох елементах `a` в `index.html`.

## TikTok Pixel

Піксель `DBCVP0BC77U4J2JQ9TUG` надсилає перегляд сторінки та стандартну подію `Contact` після натискання будь-якої кнопки Telegram. Параметр `content_category` розрізняє кнопки: `header` або `hero`. Перехід до Telegram не блокується, якщо аналітика недоступна.

У TikTok Events Manager перевірте подію `Contact` через Test Events і виберіть її як подію конверсії в налаштуваннях реклами. Подія означає натискання кнопки, а не підтверджене повідомлення у Telegram.

## Netlify

Завантажте цю директорію через Netlify Drop або підключіть її як окремий репозиторій. Команда збірки не потрібна, каталог публікації — `.`. Секрети та змінні середовища не потрібні.

Шрифти та їхні ліцензії розташовані в `assets/`.
