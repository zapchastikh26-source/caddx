# Оцінка камер Caddx

Окремий статичний односторінковий сайт українською мовою. HTML і CSS, без залежностей, зовнішніх шрифтів або обов’язкової збірки. JavaScript використовується для аналітики TikTok.

## Локальний запуск

У цій директорії виконайте:

```sh
python3 -m http.server 3001 --bind 127.0.0.1
```

Обидва посилання Telegram працюють без JavaScript. Адреса задана у двох елементах `a` в `index.html`.

## TikTok Pixel

Піксель `DBD02BJC77UASCMGFR6G` надсилає перегляд сторінки та подію `Contact` («Зворотний зв’язок») після натискання будь-якої кнопки Telegram. Обидві кнопки передають непорожній `content_id: telegram_contact`; `content_category` розрізняє `header` і `hero`. Перехід не залежить від доступності аналітики. Подія означає натискання, а не підтверджене повідомлення у Telegram.

Конструктор подій TikTok для цих кнопок не потрібен; видаліть попередні правила, щоб уникнути дублювання. Після публікації відкрийте Test Events, натисніть Telegram і перевірте `Contact` та його `content_id`. Потім виберіть `Contact` як подію оптимізації, якщо вона доступна для вибраної рекламної цілі. Серверна відправка Events API не використовується.

## Netlify

Підключіть репозиторій у Netlify. Команда збірки не потрібна, каталог публікації — `.`. Серверні функції та токени Events API для цього сценарію не потрібні.

Шрифти та їхні ліцензії розташовані в `assets/`.
